# Product Roadmap (Implementation-Oriented)

## Phase 1: Stabilization and Capability Completion

- Contracted wrapper CLI (`codesentinel.ps1`)
- Severity normalization
- Report/config/error schemas
- Deterministic fallback and exit code contracts
- Dependency diagnostics (`doctor`)
- Provenance metadata in reports

## Phase 2: Core Feature Expansion and Tier 1 Languages

- Policy profile enforcement
- Baseline suppression and diff/incremental primitives
- SARIF-first CI integration
- Secret/dependency analyzers (hybrid integration)
- Tier 1 language adapters beyond Python/JS/TS

## Phase 3: Advanced Workflows and Tier 2/Tier 3

- Triage lifecycle states
- Portfolio scanning orchestration
- Plugin/module loader and trust policy
- Tier 2 and Tier 3 language packs

## Phase 4: Platform Maturity

- Signed scan manifests and attestation
- Rule quality automation and release governance
- Air-gapped bundle lifecycle hardening
- Cross-platform runtime path (while staying Windows-first)
